# BacaTepat Flutter

Jalankan server mengikuti [panduan API](../api/README.md), kemudian jalankan `flutter pub get` dan `flutter run` dari folder ini. Gunakan `--dart-define=API_BASE_URL=https://alamat-server/api/v1` untuk menentukan server. Mode pratinjau dengan data lokal dapat dijalankan melalui `--dart-define=DEMO_MODE=true`.

Periksa kode dengan `flutter analyze` dan jalankan tes dengan `flutter test`. Uji integrasi HTTP, migrasi, worker, dan data demo dijelaskan dalam panduan API.

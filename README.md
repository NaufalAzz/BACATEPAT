# BACATEPAT

Aplikasi pembelajaran membaca permulaan untuk siswa SD kelas 1–3. Guru mengelola kelas, materi, soal, tes diagnostik dan evaluasi bacaan. Siswa mengerjakan tes dan latihan serta melihat perkembangan belajar.

| Folder | Isi |
| --- | --- |
| [api/](api/README.md) | REST API Laravel, MySQL, penilaian, worker AI, laporan PDF, migrasi dan petunjuk menjalankan server. |
| [mobile/](mobile/) | Aplikasi Flutter untuk Guru dan Siswa. Mode aplikasi menggunakan API. |
| [web/](web/README.md) | Rancangan website khusus Guru. |

Panduan instalasi dan pengujian tersedia dalam [README backend](api/README.md). Kebutuhan pembelajaran dan kontrak API dirinci dalam [BRD BacaTepat v2](BRD_BacaTepat_v2.md).
